# BlueClinik — Элитная косметология

Веб-приложение для косметологической клиники с системой записи, личными кабинетами и программой лояльности.

---

## О проекте

BlueClinik позволяет клиентам записываться на процедуры, косметологам — управлять расписанием, а администратору — контролировать работу клиники.

---

## Функционал

### Для клиентов
- Регистрация и вход в личный кабинет
- Запись на процедуры к выбранному косметологу
- Просмотр своих записей
- Отмена и перенос записи
- Программа лояльности (уровни Silver, Gold, Platinum)
- Персональные скидочные промокоды

### Для косметологов
- Просмотр записей клиентов
- Подтверждение или отмена записи
- Настройка своего расписания (дни и часы работы)
- Добавление и удаление своих услуг
- Просмотр списка своих клиентов

### Для администратора
- Статистика по пользователям, записям и выручке
- Управление пользователями (удаление)
- Добавление и удаление косметологов
- Просмотр и редактирование всех записей клиентов

## Как это работает

Все данные хранятся в localStorage вашего браузера. При первом запуске автоматически создаются администратор, четыре косметолога, а также их услуги и расписание.
Данные остаются на вашем компьютере и не передаются никуда в интернет.

## Структура проекта

- **index.html** — главная страница
- **login.html** — страница входа
- **register.html** — страница регистрации
- **dashboard.html** — личный кабинет клиента
- **admin.html** — панель администратора
- **master-dashboard.html** — кабинет косметолога
- **booking.html** — страница записи на процедуру
- **loyalty.html** — программа лояльности
- **auth.js** — основная логика работы с пользователями и данными
